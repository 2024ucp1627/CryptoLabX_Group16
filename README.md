## Project Overview

CryptoLabX is a modular cryptography toolkit developed as part of the Cryptography Laboratory course. The aim of this project is to build a reusable software framework for implementing, analyzing, and attacking cryptographic algorithms throughout the semester.

The current version establishes the project foundation, including a menu-driven command-line interface, file analysis functionality, activity logging, and an organized folder structure.
